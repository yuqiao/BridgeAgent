# 以 checkpoint 管理恢复状态，执行日志独立记录

2026-09-25 确认：默认 LangChain 运行时使用 LangGraph checkpoint 管理会话执行状态与恢复，另行记录用于观察和排障的执行日志。阶段 2 先使用内存实现，阶段 4 增加持久化与约定范围的续接能力。

相比 DeepSeek Harness 从事件日志投影模型上下文的方案，本项目复用默认运行时的状态机制，减少双重状态维护；代价是不承诺从执行日志完整重建所有模型输入。执行日志不用于驱动恢复，应用层通过运行时接口访问会话，避免自行维护第二份权威消息历史。

持久化后端、恢复点范围与外部副作用的重试规则仍需在相应阶段实施前明确。采用 checkpoint 本身不代表外部操作具备恰好执行一次的保证。
