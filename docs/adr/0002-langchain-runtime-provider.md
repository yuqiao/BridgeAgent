# 将 LangChain 执行循环作为可替换运行时实现

2026-09-25 确认：BridgeAgent 用稳定的 Agent 运行时接口隔离执行器，首个实现封装 LangChain `create_agent`，模型、工具和会话存储也通过能力接口装配。插件宿主拥有插件依赖与资源生命周期，LangChain 默认实现拥有模型—工具执行循环。

相比自研循环，这一方案复用框架已有能力，并保留以后替换整个运行时的空间；代价是需要定义适配边界，部分扩展与恢复语义受默认运行时约束。当前不再实现一套与 LangChain 竞争的循环，也不把 LangChain 图对象暴露为应用层接口。
