# 阶段 7.4：动态生命周期与重载

基线：stage7.3 / 64b0fb6。实现范围见完整性矩阵 C05/C06/C08/C14、L01–L05、H01–H03；动态 CLI 与完整 Agent 验收留给 7.5。

## 接口与行为

- DynamicHost 提供 instances/status/definition 快照，以及 mount/unmount/reconfigure/reload、refresh、set_service。实例 ID 与插件名独立，卸载后可复用 ID。
- 所有生命周期变更串行执行。`async with host.lease(context)` 保护一次调用；DynamicAgentRuntime 自动持有租约。变更暂停新调用并排空已有调用，默认最多等待 30 秒；超时报告 in-flight，未释放资源。当前保守地排空整个宿主，暂不优化为只等待受影响分支。
- 外部代码不得长期保存裸服务后在租约外调用；同步 require 是解析与装配接口，不是自动锁代理。插件激活/释放回调不得等待另一个任务对同宿主做生命周期变更；统一由外层 loader 调度。
- reconfigure 先验证候选配置，停止依赖链，再激活新实现。任一消费者激活失败也恢复旧 provider 与消费者；回滚失败时汇总异常，failed/pending 状态可查。外部副作用不属于通用事务。
- `provide(key, value, check=...)` 声明可用性；外部条件变化后 await host.refresh()，消费者随条件停用/恢复。set_service 替换值并重建消费者。
- PluginDefinition 可声明 `volatile_fields`（支持以点分隔的对象路径）与纯 `validate_config` 归一化函数，可接 Pydantic。插件从 Context.config 读取只读动态引用；仅 volatile 变化时原子更新引用，普通字段变化重挂载。配置非法则旧值不变。静态 API 1 插件不必使用这些可选字段。
- 事件扩展：internal.plugin/status、internal.config/update、internal.get/set/listener/dispatch/service、loader.volatile-update；配置/update 用异步 waterfall，get/set 用同步 continuation，listener 可返回替代 disposer。诊断通知中的异常记录后继续；业务事件、配置和操作拦截的异常向调用者传播。

## 文件配置树

DynamicLoader 读取 `version: 2` 的纯数据文档，静态 `version: 1` 行为不变。entries 为平面列表，parent 指向分组/父 entry；每项 id 唯一，name 省略表示无服务的 group。支持 config、disabled、scope（服务名→共享标签）、inject（附加依赖名）、intercept（服务配置）。父目录树循环和缺失 parent 拒绝。

load/create/update/remove、resolve/context/locate 和 save 为公开入口。移动通过 update(parent=...)；create 可指定 position。禁用父项会停用子树，恢复后重新装配；普通配置更新保留不受影响的实例。配置更新使用宿主 transaction 闸门，失败尝试恢复整个旧树。save 显式写纯 YAML，临时文件原子替换；不调用 save 的更新不改磁盘。文件来源不是代码执行表达式。

## 源码重载

SourceReloader.register(instance_id, module, attribute, dependencies=(...)) 声明可信 Python 模块及有序源码依赖清单。dependencies 按依赖先于消费者列出；不推测 Node 风格私有模块图。check 对实际 .py 内容计算 hash，重载受影响 entry，并刷新其依赖者；新模块对象与旧模块分离。编译/导入/激活失败恢复旧模块与旧定义。失败的文件版本不会在每次轮询重复激活；修复源码后重试。

require_restart(module) 标记共享 contracts；已加载的 bridge_agent 核心源码自动列入重启清单。此类文件变化抛 RestartRequired，不做危险的同进程类型替换。watch_config(path, loader) 监听配置文件；watch(stop, interval=0.25) 提供可停止的轮询，按轮询间隔合并变化。正常重载失败记录简洁诊断并继续监听，要求重启的变化结束 watcher。
