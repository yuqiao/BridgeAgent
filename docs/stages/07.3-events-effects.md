# 阶段 7.3：事件与可撤销贡献

基线：stage7.2 / 07fc2a2。Context 新增 on/once、emit/bail、parallel/serial、waterfall、select、effect、accessor/alias、logger/export_logs。注册归属激活该插件的 Context；活动期可增加 effect，停用后禁止新增。

- emit/bail 是同步 API；异步监听使用 parallel/serial，避免丢弃 Python coroutine。bail/serial 仅 None 和 False 表示继续，0、空字符串均短路。
- parallel 等待所有监听并汇总错误；waterfall 把 next 传给每个监听，可包裹或 veto，异步返回最终值。
- on 支持 prepend、global_；once 在调用前撤销，避免重入二次执行。select(predicate) 以监听者 Context 过滤；global_ 绕过过滤。默认无隐式 scope 过滤，需显式 select。
- effect 接受返回 disposer 的同步或异步工厂；返回可 await 的幂等撤销函数，status.effects 提供标签。普通同步/异步 context manager 沿用 enter_context/enter_async_context。
- accessor 计算当前值，alias 把一个已声明依赖转为另一个服务；不需要 JS 属性反射。logger 使用 Python logging 的名字、级别、Handler/Formatter；export_logs 把 handler 移除/关闭登记到插件生命周期。
- DynamicAgentRuntime 是 AgentRuntime 适配器；通过 agent.run waterfall 调用当前运行时。扩展必须返回 RunResult，可修改文本或拒绝执行。阶段 7.4 再加入在途调用保护。

TDD：tests/test_dynamic_events.py 覆盖短路、并行错误、once/prepend/filter/global、around/veto、活动期 effect、accessor/alias、日志撤销；tests/test_dynamic_agent.py 使用真实 LangChain Agent 与模型边界替身验证扩展/卸载。每项均由缺失行为的 red 推进到 green。

Review：发现重复调用旧 disposer 会误删后来同名事件的新监听列表，新增回归并修复为真正幂等。复核过滤在每次分发时应用，once 在执行前移除，并发异步分发不遗失异常。同步 API 不接受异步回调是 Python 显式 API 映射；不创建未跟踪后台任务。生命周期内部事件、配置更新与 HMR 仍由 7.4 闭合。
